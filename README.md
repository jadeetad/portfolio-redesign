# Portfolio

## Before running
Copy your existing `hero-img.jpeg` into `src/assets/hero-img.jpeg` — it's referenced by
`src/components/Hero.jsx` but wasn't included in this package since I only had the redesign
files, not your original photo.

## Run locally
```
npm install
npm run dev
```

## Deploy
Same as before — commit and push to your existing GitHub repo, Vercel will auto-rebuild.
```
git add .
git commit -m "redesign: mobile-responsive plum/cream theme"
git push
```
